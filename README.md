# LiDAR Based-automatic Braking System (LBABS)
LBABS using Velodyne VLP16 3D LiDAR, already implemented for the safety system in BRIN's three-wheeled autonomous electric vehicle.

<img width="1740" height="639" alt="image" src="https://github.com/user-attachments/assets/fdeeef0a-2829-4c85-812c-74412ba981cb" />


To run the system, ROS2 Velodyne framework needs to be installed first and configured <br>
https://github.com/ros-drivers/velodyne.git <br>

The output from Arduino/ Teensy 4.1 microcontroller can be connected to a relay to produce the necessary signal for the autonomous vehicle command. The program is located at arduino_code folder.
